# GIF 逐帧查看器

一个用滚轮逐帧查看 GIF 的桌面工具：自己解析 GIF 数据并合成每一帧，不依赖播放动画，因此能停在任意一帧上看清楚。

双击 `.gif` 文件即可用它打开；拖动滚轮上下滑动就是一帧一帧地切换。

## 为什么不用普通看图软件

GIF 在多数看图软件里只有"播放"或"停在第一帧"，看不到中间帧。常见做法的瓶颈在于：GIF 的每一帧并不都是一张完整图片，可能是局部区域、透明像素、还带"处置方式"（disposal）指令，必须逐帧叠合才能还原出正确画面。本项目自己实现了这部分解析与合成，所以每一帧都是准确的成品画面。

## 功能

- **滚轮切帧**：一格一帧，方向可正反；触控板与触屏滑动同样可用
- **逐帧合成**：支持局部帧、透明色、4 种处置方式（未指定 / 保留 / 恢复背景 / 恢复上一帧）、隔行扫描
- **多种打开方式**：双击 GIF、拖到窗口或 exe 图标、系统文件对话框、Ctrl+V 粘贴
- **缩略帧条**：底部按帧显示缩略图，点击直达；也可用滑杆定位
- **帧信息**：帧延迟、时间位置、帧区域坐标、处置方式、循环次数、画布尺寸
- **画面查看**：适应窗口 / 1:1 / Ctrl+滚轮缩放、放大后拖动平移、像素锐利切换
- **导出**：把当前帧存为 PNG（原始分辨率）
- **纯本地**：图片不上传，不联网解码

## 快捷键

| 操作 | 按键 |
| --- | --- |
| 逐帧移动 | 滚轮上下 / `↑` `↓` `←` `→` |
| 播放、暂停 | `Space` |
| 跳 10 帧 | `PgUp` / `PgDn` |
| 首帧 / 末帧 | `Home` / `End` |
| 缩放画面 | `Ctrl` + 滚轮 |
| 平移画面 | 放大后按住拖动 |

## 两种用法

**1. exe（推荐）**

按下面的构建步骤打包出 `GIF逐帧查看器.exe`，双击运行，单文件、免安装。依赖系统自带的 WebView2 运行时（Windows 10/11 默认已装）。

想让它成为 `.gif` 的默认打开程序：右键任意 GIF → 打开方式 → 选择其他应用 → 找到该 exe → 勾选"始终使用"。设置后双击 GIF 即直接打开并载入该文件。

**2. 单文件网页版**

直接双击 `GIF逐帧查看器.html`，在浏览器里使用，功能与 exe 一致（打开文件走浏览器自带对话框）。

## 从源码构建

```bash
# 环境：Windows + Python 3.10+
pip install pywebview pyinstaller pillow

# 直接以桌面窗口运行
python app.py

# 生成图标 → 打包单文件 exe（产物在 dist/ 下）
python build/make_icon.py
pyinstaller --noconfirm --onefile --windowed ^
  --name "GIF逐帧查看器" ^
  --icon "build/icon.ico" ^
  --add-data "GIF逐帧查看器.html;." ^
  app.py
```

> 仓库里没有放 `.exe` 与 `icon.ico` 这类二进制文件，图标用上面的脚本现场生成。

## 技术实现

- **GIF 解码**：`GIF逐帧查看器.html` 里内置解析器，读取逻辑屏幕描述符、全局/局部调色板、图形控制扩展（GCE）、应用扩展（NETSCAPE 循环次数）与图像块，自行完成 GIF 变体 LZW 解码与隔行扫描重排，再逐帧按 disposal 规则合成到统一的 RGBA 画布上。
- **桌面外壳**：`app.py` 用 pywebview（WebView2）承载同一个页面；通过 `js_api` 暴露原生"打开 GIF / 另存 PNG"对话框；双击文件时读取命令行传入的路径并推给页面。
- **单文件交付**：PyInstaller `--onefile`，HTML 作为数据文件一起打包。

## 已知限制

- 只处理 GIF；其他图片格式会提示不支持
- 帧数极多的 GIF（> 800 帧）不显示缩略帧条，改用滑杆定位，避免一次性生成过多画布
- 帧数据全部合成后驻留内存，超大分辨率 GIF 会占用较多内存
- 导出为 PNG 时保留透明通道，不保留原帧的局部区域裁切
